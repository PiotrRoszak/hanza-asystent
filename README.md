# Hanza Asystent

Wewnętrzna aplikacja sklepu hanza_store wspierająca obsługę
klientów na platformie Allegro.

## Cel i zakres działania

Aplikacja korzysta z Allegro REST API do:
- odczytywania wiadomości i historii rozmów,
- odczytywania ofert oraz zamówień,
- przygotowywania propozycji odpowiedzi na pytania klientów.

Na etapie testowym odpowiedzi wymagają zatwierdzenia przez
właściciela sklepu. Docelowo aplikacja umożliwi automatyczne
wysyłanie odpowiedzi w wybranych kategoriach pytań.

## Dostęp

Aplikacja jest przeznaczona wyłącznie na potrzeby własnego
sklepu hanza_store. Autoryzacja odbywa się przez OAuth 2.0
Device Flow.
